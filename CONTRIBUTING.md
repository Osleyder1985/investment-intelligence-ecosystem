# Contribuir

## Flujo de trabajo

1. Registrar cada necesidad o defecto mediante un Issue en español.
2. Describir problema, causa, solución propuesta, evidencia, alcance y criterios de aceptación.
3. Crear una rama específica y un Pull Request vinculado al Issue.
4. Revisar consistencia metodológica, trazabilidad, reproducibilidad y pruebas.
5. No fusionar cambios que introduzcan umbrales, pesos o conclusiones sin justificación y validación.

## Reglas documentales

- Mantener nombres de archivos y directorios en inglés.
- Redactar la documentación en español, conservando términos técnicos cuando corresponda.
- Citar fuentes primarias y registrar fecha de consulta.
- Diferenciar requisitos aprobados, propuestas, hipótesis y elementos pendientes.
- No declarar conformidad o certificación ISO sin evaluación formal independiente.
